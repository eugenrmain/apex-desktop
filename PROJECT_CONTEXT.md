# Apex Desktop context (APX Studios)

## Stack and build

- C# / .NET 8, WinUI 3 (Windows App SDK 1.8), unpackaged self-contained win-x64. Local SDK in `.tools/dotnet` (run `scripts/setup.ps1` once).
- One build command: `powershell -File scripts/build.ps1` → output is always `artifacts/apx-release-1.0.0/` (enforced by the script). It kills running Apex first.
- Helper executables (Sensors, Settings, Capture, Network, Recovery) are separate projects staged into the same output folder.
- Icons/backdrop/sound are generated by `scripts/generate_assets.py` (PIL). Never hand-edit the PNG/ICO files.

## File map

- `MainWindow.cs`: window shell, title bar, rail, `ShowPage` router, `Text()` typography helper, Home page.
- `MainWindow.Brand.cs`: Geist font families and `FlameMark()` vector logo (path data shared with `Assets/Apex.svg` and the asset script).
- `MainWindow.Diagnostics.cs`: background monitoring loop (footer + Diagnostics page). `Platform/WindowsMonitoring.cs`: sampler.
- `MainWindow.<Feature>.cs`: one partial per workspace (Compress, Media, SystemClean, Tools, Performance, GameBooster, Recordings).
- `MainWindow.Verification.cs`: `--verify*` self-test and in-app capture mode. Keep it compiling when renaming UI.
- `Platform/`: Win32/P-Invoke wrappers. `Services/`: models and pure logic. `App.xaml`: control theme overrides.

## Design laws

- Dark glass: Mica (BaseAlt) backdrop + `#A6070B18` root tint; text `#EDF3FF` / `#A9BAD4`; accent `#67D8FF`.
- Logo: two-tongue flame (82% of the original width), vertical gradient `#7A45E6` → `#4F4BD8` → `#2F62F0`, white bolt. No monograms.
- Type: Geist only (SIL OFL, `Assets/Fonts`). Regular for body/controls, Medium for every heading (large titles tracked -12). No Light weights.
- Control font comes from `ContentControlThemeFontFamily` inside App.xaml ThemeDictionaries; a plain override is ignored.
- Every TextBlock goes through `Text()` or sets `GeistRegular`; never rely on the default system font.
- Title bar: flame + single "Apex Desktop" in Geist Medium; no mixed fonts.

## Performance laws

- Footer samples totals only (`SampleAsync(token, detailed: false)`): every 2 s active, 5 s inactive, nothing while minimized/hidden.
- Full process/network walks only on the Diagnostics page (1 s). Disk free space and power plan refresh every 30 s or on navigation.
- Only touch UI when text changes. Idle on Home measured 0.03% total CPU (was 4.35%) on 2026-10-22.
